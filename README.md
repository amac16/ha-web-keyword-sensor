# Web Keyword Sensor Home Assistant App Repository

This repository contains the **Web Keyword Sensor** Home Assistant app.

## Add to Home Assistant

Publish this repository to GitHub, then in Home Assistant open:

**Settings → Apps → App Store → ⋮ → Repositories**

Add the GitHub repository URL. The app will then appear under **Local apps** or
as a custom repository app.

The app source is in [`web-keyword-sensor/`](web-keyword-sensor/).
